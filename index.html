초대받아 참가

초대 정보를 확인했어요. 이름을 쓰고 참가해줘.

방 코드만으로는 참가할 수 없어요. 링크는 두 사람끼리만 공유해줘.

초대 정보는 이 브라우저에만 저장해요. 공유 기기에서는 아래에서 지울 수 있어요.

혼자 연습

홈 화면에 추가 · 사용 안내

iPhone Safari: 공유 → 홈 화면에 추가. Android Chrome: 메뉴 → 홈 화면에 추가 또는 바로가기 만들기. 두 사람 모두 같은 주소와 같은 브라우저를 사용해줘.

홈 화면 아이콘으로 열어도 인터넷 연결과 방장 접속이 필요해요. 카톡 인앱에서 생긴 저장은 Chrome/Safari와 공유되지 않을 수 있어요.

실제 두 폰 검사·기록
규칙과 사용 범위
BBang 기본 맞고 1 · 실사용 베타

48장, 손패 10장씩, 바닥 8장. 손이나 바닥에 같은 월 4장이 있으면 다시 나눠요. 총통은 사용하지 않아요.

7점부터 고/스톱. 1고 +1점, 2고 이상 +2점. 3고부터 ×2, 4고 ×4… 마지막 손패로 새로 난 경우 자동 스톱. 고 이후 점수가 오르지 않고 패를 모두 쓰면 나가리.

3광 3점(비 포함 2), 4광 4, 5광 15. 열끗·띠는 5장부터 1점씩. 고도리 5, 홍단·청단·초단 각 3. 피는 10장부터 1점씩, 쌍피는 2장.

쪽·따닥·바닥 같은 월 3장 먹기·싹쓸이는 상대 피 한 장씩 가져와요. 쌍피만 있으면 그 한 장을 가져와요. 바닥 3장이 처음부터 깔린 경우도 동일해요. 자뻑 추가 보너스·3뻑 승리는 없어요. 마지막 전체 차례는 싹쓸이 보너스 없음.

피박: 이긴 사람 피 점수 있음, 상대 피 1~5. 광박: 이긴 사람 광 점수 있음, 상대 광 0. 멍박: 이긴 사람 열끗 7장 이상. 고박: 진 사람이 고 선언. 각 ×2.

흔들기: 내 차례 손에 같은 월 3장이 있으면 공개 선언. 월마다 판당 한 번, 승리 시 ×2. 폭탄·9월 열끗 쌍피 전환은 사용하지 않아요. 나가리마다 다음 판 배율 ×2 누적.

돈·환전·결제 없는 개인용 점수 게임. 방장은 전체 패를 관리하므로 부정행위 방지용 경쟁 서비스가 아니에요.

방 코드는 6자리예요. 이전 버전과 연결되지 않아요. 카톡에서 열었다면 Chrome 또는 Safari로 다시 열어줘. 서로 다른 네트워크 연결은 환경에 따라 실패할 수 있어요.

연결을 확인 중이에요.

상대가 돌아올 때까지 진행을 멈춰요. 방장은 초대 링크를 다시 보내고, 참가자는 다시 연결을 눌러줘. 참가자는 최대 5회 자동 재시도해요. 복구가 끝날 때까지 패를 낼 수 없어요.

게임 방법과 점수

같은 월을 맞춰요. 노란 테두리는 바닥과 맞는 패, 파란 테두리는 선택할 패예요. Tab·Enter·스페이스로도 선택할 수 있어요.
