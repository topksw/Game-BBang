# Game BBang · 1.0.0-beta.3 그래픽 미리보기

무료·초대 전용 2인 맞고. 실제 두 폰 승인이 남은 실사용 베타입니다.

## 주소
- 실사용: https://topksw.github.io/Game-BBang/
- 검증용: https://topksw.github.io/Game-BBang/preview/
- 자동 검사: 각 주소 뒤에 tests.html

이름 입력 → 새 방 만들기 → 초대 공유 → 상대가 같은 버전에서 참가. 코드만으로는 입장할 수 없습니다. 카톡에서는 Chrome/Safari로 열어 주세요.

## 복구
같은 브라우저로 돌아오세요. 방장은 이전 판 이어하기, 참가자는 최신 초대 링크를 사용합니다. 방 코드가 바뀌어도 변경되지 않는 roomId로 같은 자리를 찾습니다. 다른 기기/다른 브라우저로 자리 이동은 지원하지 않습니다. 자동 재접속은 최대 5회이며 이후 다시 연결 버튼을 누르세요. 호스트가 닫혀 있는 동안 방은 진행되지 않습니다.

## 저장·업데이트
앱 버전과 저장 형식을 분리했습니다. beta.1의 정상 저장은 형식 2로 변환하고 원본을 보관합니다. 최근 저장이 손상되면 직전 정상 백업을 사용하고 이를 알립니다. 저장 공간 삭제·시크릿 브라우징 종료·다른 기기에서는 복구가 보장되지 않습니다. 새 버전 알림이 보이면 판을 마치고 게임을 나간 뒤 양쪽 모두 새로고침하세요.

## 화면
패 크게, 획득 패 보기, 기본 꺼짐인 소리 설정, 오류 진단 복사. 연결이 끊기면 패 선택·고/스톱·다음 판 진행을 막습니다. 진단에는 이름·손패·방 코드·초대/자리 비밀값을 넣지 않습니다. 자동 개인정보 수집은 없습니다.

## 개발·검사
engine.js: 규칙/저장 상태 검증. network.js: 연결/저장/자리. artwork.js: 직접 제작한 월별 벡터 화투. ui.js/style.css: 화면·상태 갱신과 분리된 연출. PeerJS 1.5.4 원본 고지 유지.
Node 22에서 node test-runner.cjs 또는 브라우저 tests.html. 규칙·저장 65개와 가상 연결·복구 25개 및 원화 8개 검사, 고정 seed 1000판 카드 보존/종료 검사 포함. 가상 통신은 실제 폰 테스트가 아닙니다.

## 공개 절차
main과 staging을 각각 검사한 뒤 하나의 Pages 산출물로 배포합니다. main은 루트, staging은 preview 경로입니다. preview는 저장 키·Peer 네임스페이스가 분리됩니다. 검사가 실패하면 package/deploy가 실행되지 않습니다. 상세 절차·롤백은 RELEASE.md.

## 범위·한계
BBang 기본 맞고 1 고정 규칙(RULES.md). 폭탄·총통·3뻑·9월 전환 미지원. 회원가입·결제·환전·공개 매칭 없음. 호스트가 전체 패를 관리하므로 경쟁용 부정행위 방지는 아닙니다. 기본 PeerJS 중개 서비스에 의존하며 별도 TURN은 없습니다. 서로 다른 망에서 연결 실패가 확인되면 TURN을 검토하고, 방장 종료 후에도 방 유지가 필요하면 서버 상태 보관 구조를 별도로 선택해야 합니다.


## 그래픽 미리보기
원화 검토: [gallery.html](gallery.html), 대표 6종과 48장 전체. 패 이동·뒤집기·획득은 260~300ms이며 규칙·통신을 기다리게 하지 않습니다. 동일 revision, 첫 진입, 복원 점프, 연결 해제/복구, 백그라운드에서는 연출을 억제합니다. 동작 줄이기 환경을 존중합니다. 연출 테스트의 상세와 실기기 제한은 GRAPHICS.md. 루트 실사용 beta.2는 그대로 유지합니다.
