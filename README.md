# Game BBang · 1.0.0-beta.1

두 사람을 위한 무현금 맞고. **실사용 베타**, 실기기 승인은 아직 받지 않았습니다.

## 사용
1. https://topksw.github.io/Game-BBang/ 에 두 사람 모두 새로 접속합니다.
2. 방장이 이름과 새 방 만들기를 선택하고 초대 링크를 둘끼리 공유합니다.
3. 참가자가 링크로 열고 이름과 참가를 선택합니다. 코드는 6자리이며, 링크의 비밀값도 필요합니다.
4. 화면을 닫으면 같은 브라우저로 복귀합니다. 방장은 이전 판 이어하기, 참가자는 원래 초대 링크를 사용합니다. 방 코드가 바뀌면 새 링크를 보내세요.

이전 4자리 방·저장본은 호환되지 않으며 삭제하지 않고 그대로 둡니다. 베타 버전이 다르면 접속을 거절합니다.

## 구조
- engine.js: 고정 규칙·점수·상태 전이, DOM/네트워크 없음
- network.js: PeerJS, 초대 비밀값·기기 자리, revision/round/id 중복 방지, heartbeat/재연결, 버전별 저장
- ui.js / style.css: 직접 제작한 벡터 그림과 모바일/키보드 화면
- peerjs.min.js: PeerJS 1.5.4 배포 파일, 원본 라이선스 고지 보존
- tests.js / tests.html / test-runner.cjs: 정답 테스트와 고정 seed 카드 보존 검사

## 검증
브라우저에서 tests.html을 열거나 Node 22 이상에서 node test-runner.cjs를 실행합니다. 프로그램 변경 후 이 검사를 통과한 버전만 배포하세요. 전체 규칙은 RULES.md, 실기기는 DEVICE-CHECKLIST.md.

## 범위·보안·저장
회원가입/결제/환전/광고 없음. 호스트가 전체 패를 관리하므로 적대적인 상대를 위한 공정성 보장은 없습니다. 참가자에게는 자신의 손패와 공개 상태만 전송합니다. 초대 비밀값은 URL fragment로 전달되고 자리 키는 브라우저에 저장됩니다. 링크를 공개하지 마세요. 같은 브라우저의 다른 탭은 같은 자리 정보에 접근할 수 있습니다.
저장 데이터는 방장 브라우저 localStorage에만 존재합니다. 저장 공간 삭제/다른 기기에서는 복구되지 않습니다. 개인정보 분석·서버 오류 수집은 없습니다. PeerJS 기본 연결 중개 서비스를 이용하고 TURN을 별도 운영하지 않습니다. 데이터망 제한에 따라 직접 연결이 안 될 수 있습니다. 유료 서비스나 서버 이동은 이번 릴리스에 포함하지 않았습니다.

## 배포/롤백
GitHub Pages main 루트에서 제공. 외부 npm 설치 없이 정적 파일 전체를 게시합니다. engine/network/ui/style을 같은 커밋으로 배포하며 버전 문자열과 query를 함께 변경합니다. CI는 정답 테스트 실패 시 실패 상태를 표시합니다. Pages 자동 배포와 독립이므로 실패 상태이면 반드시 배포를 중단하거나 즉시 되돌려야 합니다.
이전 공개 단일 파일은 rollback-v2.html로 보존합니다. 사고 시 해당 파일 내용을 index.html로 복원하거나 직전 커밋으로 되돌립니다. 기존 v2 저장 키는 유지됩니다.
